# Finance Calculator (Python)

A python application that calculates returns on investment deposits (simple or compound interest) and determines repayments for home loans (bonds). 

## Features
- **Investment Calculator:** computes total accumulated wealth using either simple ($A = P(1 + rt)$) or or compound ($A = P(1 + r)^t$)  interest formulas.
- **Bond Repayment Calculator:** Calculates monthly mortgage/bond repayments based on interest rates, loan principal, and duration.
- **Input Handling:** Normalizes user inputs using case-insensitivity and string stripping to prevent runtime execution errors. 

## Tech Stack
- Python 3.x
- 'math' module
